# 📋 Dashboard de Projetos | Power BI

Dashboard interativo que acompanha o funil comercial de projetos: **leads**, **oportunidades** e **projetos fechados**, com os valores **orçados**, **pagos** e **descontos concedidos**, além da evolução ao longo do tempo e da visão por setor.

## ✨ Recursos

- Indicadores de **Total de Leads**, **Oportunidades**, **Projetos Fechados**, **Total Orçado**, **Total Pago** e **Total de Desconto**
- Comparação entre valor orçado e valor pago por data de início
- Funil de oportunidades por status
- Evolução dos projetos fechados ao longo do tempo
- Filtro por setor
- Tooltips personalizados com oportunidades por setor

## 🛠️ Tecnologias

Power BI Desktop · DAX · Power Query · Visual personalizado (filtro por setor)

## 🚀 Como abrir

Baixe o arquivo `.pbix` e abra no **Power BI Desktop**.
